================================================================================
Line comment ends at the tag close on the same line
================================================================================
{% x = 1; // note %}
--------------------------------------------------------------------------------

; DIVERGENCE FROM UCODE (deliberate, editor-friendly). In ucode a `//` line
; comment runs to the end of the line and SWALLOWS a same-line `%}`, leaving the
; tag open until EOF. Here the comment instead stops before `%}` so the close is
; recognised — what a user typing this single line almost always intends. The
; common multi-line style (comment on its own line, `%}` on the next) is
; unaffected and matches ucode exactly.

(markup
  (statement_tag
    open: (statement_tag_open)
    (expression_statement
      (assignment_expression
        left: (identifier)
        right: (number)))
    (comment)
    close: (statement_tag_close)))
