# Tutorials

Lessons that take you from nothing to a working result, one per audience.

| building an editor integration, a language server or another tool on the grammars | [Build on the grammars](build-on-the-grammars.md): load the grammars through the Node.js binding, walk a tree by field names, run the highlights query, and follow the doc-comment injection |
