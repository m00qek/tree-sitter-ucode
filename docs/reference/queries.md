# Queries and captures

## Files

| File | `ucode/queries/` | `ucode_markup/queries/` | `ucdocs/queries/` | `editors/helix/queries/<lang>/` | Read by |
| --- | --- | --- | --- | --- | --- |
| `highlights.scm` | source | generated | source | generated, all three | tree-sitter-highlight, Neovim, Helix |
| `injections.scm` | source | generated | | generated, `ucode` and `ucode-markup` | tree-sitter-highlight, Neovim, Helix |
| `locals.scm` | source | generated | | generated, `ucode` and `ucode-markup` | tree-sitter-highlight, tree-sitter-tags, Neovim, Helix |
| `tags.scm` | source | generated | source | generated, all three | tree-sitter-tags, GitHub code navigation |
| `folds.scm` | source | generated | | | Neovim (`vim.treesitter.foldexpr()`) |
| `indents.scm` | source | generated | source | written by the Helix generator, `ucode` and `ucode-markup` | nvim-treesitter `indentexpr`; Helix |
| `textobjects.scm` | source | generated | | written by the Helix generator, `ucode` and `ucode-markup` | nvim-treesitter-textobjects; Helix |

- `ucode_markup/queries/` is generated from `ucode/queries/` by
  `scripts/generate-markup-queries.js`: each file is its `ucode` counterpart
  with `(program)` rewritten to `(markup)`, plus template-only patterns in
  `highlights.scm` and `tags.scm`.
- `editors/helix/queries/` is generated by `scripts/generate-helix-queries.js`.
  Its directories are named after Helix languages: `ucode`, `ucode-markup`,
  `ucdocs`.
- `tree-sitter.json` lists only highlights, locals, injections and tags.

## Predicates and directives

| File | Predicates and directives | Applied by |
| --- | --- | --- |
| `highlights.scm` (all grammars) | `#any-of?` | any tree-sitter runtime |
| `injections.scm` | `#any-of?`, `#set! injection.language` | any runtime; the host reads `injection.language` |
| `locals.scm` | `#set! local.kind` | metadata for the host; tree-sitter-highlight ignores it |
| `tags.scm` | `#not-any-of?`; `#match?` (`ucode_markup` only) | any runtime |
| `tags.scm` | `#strip!`, `#select-adjacent!` | tree-sitter-tags only |
| `indents.scm` | `#not-kind-eq?`, `#set! indent.immediate`, `#set! indent.start_at_same_line` | nvim-treesitter only |
| `folds.scm`, `textobjects.scm`, ucdocs `indents.scm` and `tags.scm` | none | |
| Helix `indents.scm` | `#not-kind-eq?`, `#set! "scope" "all"` | Helix |
| other Helix files | as their source files above | |

The Node.js `tree-sitter` runtime 0.25.1 rejects a query that contains
`#strip!`, `#select-adjacent!` or `#not-kind-eq?`; web-tree-sitter 0.27.1
and py-tree-sitter 0.26.0 accept them. See
[Choose a query set](../how-to/choose-query-set.md).

## highlights.scm

The repository's own files use nvim-treesitter capture names.

| Capture | On |
| --- | --- |
| `@variable` | identifiers |
| `@variable.member` | property names, shorthand properties |
| `@variable.parameter` | function and arrow parameters, including rest parameters |
| `@variable.builtin` | `this`, `ARGV`, `SCRIPT_NAME`, `REQUIRE_SEARCH_PATH`, `global` |
| `@function` | names of function declarations and named function expressions |
| `@function.method` | object keys whose value is a function or arrow function |
| `@function.call`, `@function.method.call` | called functions and methods |
| `@function.builtin` | calls to ucode's builtin functions (list below) |
| `@keyword` and its subgroups `.conditional`, `.repeat`, `.return`, `.exception`, `.import`, `.function`, `.storage`, `.operator` | keywords |
| `@keyword.directive` | the `#!` line |
| `@string`, `@string.escape`, `@string.regexp` | strings, escapes, regex literals including their slashes |
| `@number`, `@boolean`, `@constant.builtin` | numbers, `true`/`false`, `null` |
| `@comment`, `@comment.documentation` | comments; doc comments are both |
| `@operator` | operators |
| `@punctuation.bracket` | `(` `)` `[` `]` `{` `}` |
| `@punctuation.delimiter` | `,` `;` `.`, and `:` after object keys, case labels and alt-syntax headers |
| `@punctuation.special` | `${` and `}` of a template substitution; template tag delimiters |
| `@spell` | comment text, for spell checking |

`ucode_markup` adds `@punctuation.special` on every tag delimiter node and
`@comment` on `comment_tag`. Template `raw_text` is not highlighted.

| Capture | On |

| `@type`, `@type.builtin`, `@type.parameter` | named types; primitive, `any`, `list`, `dict` and `function` types; `@template` parameters |

## injections.scm

| Injected language | Into |
| --- | --- |
| `ucdocs` | every `doc_comment` |
| `regex` | every `regex_pattern` |
| `printf` | the `string_fragment` of the first argument of `printf()` and `sprintf()` when it is a string literal |

Template `raw_text` is not injected. See
[Set up injections](../how-to/set-up-injections.md#template-text-opt-in) to opt in.

## locals.scm

| Capture | On |
| --- | --- |
| `@local.scope` | the root, function declarations and expressions, arrow functions, `statement_block`, the four `for` statements, `catch_clause`, `statement_list` (alt-syntax bodies), `switch_body` |
| `@local.definition` | declared names; each pattern sets `local.kind` to `function`, `var`, `parameter` or `import` |
| `@local.reference` | identifiers |

Only the plain `@local.definition` capture is used, because
tree-sitter-highlight and tree-sitter-tags accept no other. The Helix copy
uses Helix's `@local.definition.<scope>` names instead, derived from
`local.kind`.

## tags.scm

| File | Captures |
| --- | --- |
| `ucode`, `ucode_markup` | `@definition.function` (function declarations and functions assigned to a name), `@definition.constant` (exported `const` / `let` that are not functions), `@reference.call` (calls, except to builtins), `@name`, `@doc` |
| `ucdocs` | `@definition.type` (`@typedef` names), `@reference.type` (named types), `@reference.module` (module types), `@name` |

`@doc` is the preceding comment or doc comment. The patterns use
tree-sitter-tags' `#strip!` (remove the comment markers) and
`#select-adjacent!` (keep only a comment on the line directly above). Other
query consumers see these as plain metadata.

In templates, a doc comment in its own tag (`{% /** Doc. */ %}`) attaches to
the declaration in the next tag, as long as only whitespace separates the two
tags.

## folds.scm

`@fold` on statement blocks, `switch` bodies, objects, arrays, alt-syntax
`if` / `for` / `while` statements, colon-form functions, `case` and `default`
clauses, comments, doc comments, and runs of consecutive imports.

## indents.scm (Neovim)

Captures for nvim-treesitter's `indentexpr`: `@indent.begin`, `@indent.end`,
`@indent.branch`, `@indent.dedent`, `@indent.auto`, `@indent.ignore`. A line
that starts with `}`, `]`, `)` or an alt-syntax end keyword is dedented;
braceless bodies and empty `case`s are indented. `ucdocs/queries/indents.scm`
marks the whole `document` `@indent.auto`, so doc comment lines keep their
indentation.

## Helix capture names

The Helix highlights rename these captures; all others keep their name, and
`@spell` is dropped:

| Neovim | Helix |
| --- | --- |
| `@variable.member` | `@variable.other.member` |
| `@boolean` | `@constant.builtin.boolean` |
| `@number` | `@constant.numeric` |
| `@string.escape` | `@constant.character.escape` |
| `@function.call` | `@function` |
| `@function.method.call` | `@function.method` |
| `@keyword.conditional` | `@keyword.control.conditional` |
| `@keyword.repeat` | `@keyword.control.repeat` |
| `@keyword.return` | `@keyword.control.return` |
| `@keyword.exception` | `@keyword.control.exception` |
| `@keyword.import` | `@keyword.control.import` |
| `@module` | `@namespace` |
| `@comment.documentation` | `@comment.block.documentation` |
| `@markup.link` | `@markup.link.url` |

Locals: `local.kind` `var` and `import` become `@local.definition.variable`,
`parameter` becomes `@local.definition.variable.parameter`, and `function`
becomes `@local.definition.function`.
