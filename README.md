# tree-sitter-ucode

Tree-sitter grammars for [ucode](https://github.com/jow-/ucode), the scripting
language used in OpenWrt: `ucode` for scripts, `ucode_markup` for templates,
and `ucdocs` for `/** */` doc comments.

**Documentation: <https://m00qek.github.io/tree-sitter-ucode/>**
